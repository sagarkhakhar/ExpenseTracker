```dart
// Handle authentication state changes and errors
supabase.auth.onAuthStateChange.listen((data) {
  final AuthChangeEvent event = data.event;
  final Session? session = data.session;
  // Handle successful state changes
}, onError: (error) {
  // Handle authentication errors
  if (error is AuthException) {
    // Handle Supabase authentication errors
  } else {
    // Handle network or other errors
  }
});
```

**Error Recovery Patterns:**
```dart
try {
  final response = await supabase.auth.signInWithPassword(
    email: email,
    password: password,
  );
} on AuthException catch (error) {
  // Handle specific authentication failures
  switch (error.statusCode) {
    case '400':
      return 'Invalid email or password';
    case '422':
      return 'Email not confirmed';  
    default:
      return 'Authentication failed. Please try again.';
  }
} catch (error) {
  // Handle network or unexpected errors
  return 'Connection error. Please check your internet.';
}
```

### Comprehensive Error Taxonomy

**Authentication Error Categories:**

1. **Network Errors:**

2. **Credential Errors:**

   - Incorrect password
   - Account not found
   - Email not confirmed

3. **Account State Errors:**
   - Account disabled
   - Too many failed attempts
   - Account migration failures
   - Session expired

4. **System Errors:**
   - Local storage failures
   - Authentication provider initialization failure
   - State synchronization errors
   - Data migration failures
